# 售后回复模板

您好，请先确认 XQ 包版本、上游版本和复现步骤。若需要诊断，请运行包内只读工具，打开新生成的 TXT，确认已脱敏后只发送相关 finding。

请不要发送 API Key、密码、Cookie、Token、Bearer/Basic 凭据、远程控制码、完整环境变量/配置、聊天或会话内容、浏览器数据、SSH 私钥或原始日志。我们不会要求这些信息，也不会代填凭据或远程控制电脑。

本售后包含一次范围内文字答疑、已验收路径的说明和约定范围内损坏文件重发；不包含模型账单/退款、额度、第三方插件、远程支持、永久更新或兼容性保证。进一步日志请使用官方 Hub 的已脱敏支持上下文，由您自行审查和决定是否发送。
