遇到问题：常见问题

返回总览只读诊断售后边界

为什么没有 Windows 的 openclaw.exe？

标准 Hub 路径可能把 CLI 和 Gateway 放在官方自管的 WSL 中。XQ 诊断会把 Managed WSL Gateway 与额外的 Windows 原生 CLI 分开报告，不能用其中一条路径代替另一条。

诊断显示“未找到”是不是安装失败？

不一定。未安装时也会生成成功的说明报告；某一探针失败只会成为该探针的 finding。请结合 Hub 页面、WSL 状态和报告中的成功标志判断。

可以让售后远程控制吗？

不在本资料包范围内。不要发送远程控制码、密码、Cookie、API Key 或完整日志。需要进一步信息时，使用官方 Hub 自带的已脱敏支持上下文，并由你自行决定是否发送。

为什么不提供“一键修复”？

本包的诊断是只读的，避免未经确认改变服务、配置或权限。请按官方界面和官方卸载/恢复流程操作。

模型为什么收费？

模型提供商可能按请求、输入输出量或订阅收费；费用、额度、退款和停用由提供商决定，XQ 不承诺免费、永久或无限。

PowerShell 被拦截怎么办？

可见的 CMD 启动器只对本次 PowerShell 进程使用一次性 Bypass，并保留可检查的 .ps1。它不会永久修改执行策略、关闭 Defender 或添加排除项。

仍需帮助时，请阅读售后页并提交最少必要信息。
