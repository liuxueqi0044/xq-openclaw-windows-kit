附加说明：能力与最小权限

返回总览回到第 3 步
以实际界面为准：官方 Hub onboarding 可能有 Capabilities/Settings 页面，上游默认配置也可能随版本变化。XQ 不声称上游默认一定关闭某项能力。

首次测试建议

在官方 Capabilities/Settings 中，优先选择 operator-only 或同等的最小能力选项（名称以实际界面为准）。完成最小权限、无敏感数据的测试对话后，再逐项理解风险。

  • 初次测试先关闭 Node Mode、system.run、屏幕、相机、位置、麦克风等 Windows 能力。
  • 不勾选“随 Windows 启动”或类似后台自启动选项，除非你已理解官方组件的权限和数据影响。
  • Agent 可能按官方授权访问文件、网络或终端；请使用专门的无敏感数据目录和低权限账户测试。
  • 日后确有需要时，由用户在官方界面自行开启单项能力并复核权限；XQ 不代开、不扩大权限。
不要把“完成基础对话”理解为允许访问全部文件、网络、终端或设备。权限越大，越应先备份重要文件并确认可撤销。
本页是安全补充，不增加五步主流程；所有能力由官方 OpenClaw 组件决定。
