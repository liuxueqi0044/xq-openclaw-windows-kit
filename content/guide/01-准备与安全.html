开始前检查

  • 系统在 XQ 已验收范围内：Windows 11 x64。可在“设置 → 系统 → 系统信息”查看 Windows 版本，在“系统类型”查看 x64；其他系统不属于本资料包的承诺范围。
  • BIOS/系统已允许硬件虚拟化，Windows 已启用 WSL2；首次设置可能需要重启。官方 Hub 通常按当前用户安装，不要求你先打开管理员终端；启用系统功能时如出现 Windows 可见确认，按官方提示操作。
  • 为 WSL 和模型工具预留足够空间，先备份重要文件；首次测试请使用无敏感数据的环境。
  • 只从本资料包和官方 OpenClaw 界面获取文件；不要使用网盘缓存、破解补丁或陌生插件。
费用提醒：OpenClaw 本体可从官方渠道免费获取；你购买 XQ 的是整理、中文引导、只读诊断和约定范围内支持。模型提供商、网络和云资源可能另行收费；API Key 的额度、账单、退款和停用规则由对应模型提供商决定；XQ 不承诺免费、永久或无限使用。
凭据与权限提醒：任何人以“帮你配置”为理由索要 API Key、密码、Cookie、验证码或远程控制码，都不在本资料包流程内。Agent 可能按官方授权访问文件、网络或终端；首次测试请使用最小权限和无敏感数据环境。XQ 售后不需要这些秘密。
