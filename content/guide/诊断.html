XQ 只读诊断说明

返回总览售后边界
运行姿态：只读、无上传、无提权。每个探针独立超时；失败会写成可读 finding，仍尽量生成报告。

会检查什么

  • Windows 版本、架构、管理员状态和可用磁盘（有限字段）。
  • 官方 Hub 的有限安装信息与签名状态。
  • OpenClawGateway WSL 是否存在，以及 WSL 内以 openclaw 用户运行版本、doctor JSON、gateway status JSON。
  • 若 Windows PATH 中存在额外原生 CLI，单独运行相同三条只读命令。

不会做什么

  • 不会安装、修复、重启、停止、修改、删除或提权。
  • 不会读取完整环境变量、OpenClaw 配置、会话、浏览器数据、SSH 目录、剪贴板或任意原始日志。
  • 不会把命令行密码/token 写入参数，不会联网或上传报告，不会覆盖旧报告。

报告怎么交给售后

先用文本编辑器打开新生成的 TXT，确认没有个人信息或秘密；只在你愿意时发送。若需更深入信息，请使用官方 Hub 的已脱敏 support context/debug bundle，并自行审查内容。

PowerShell 提示：“运行诊断工具.cmd”只对当前进程使用 -NoProfile -ExecutionPolicy Bypass，不会永久更改执行策略。不要把脚本复制到系统目录。
诊断结果仅反映运行当下的有限探测，不是安全审计，也不代表 XQ 对上游行为作保证。
