第 3 步：在官方 Hub 做本地设置

上一步总览下一步

推荐路径

在官方 Hub 中选择本地设置。这是 XQ 首版唯一完整验收的路径：官方 Hub 创建并管理默认的 OpenClawGateway WSL Gateway。

  1. 打开官方 Hub 的本地设置入口，按其提示启用 WSL2/虚拟化。
  2. 允许官方 Hub 创建默认 WSL 发行版；不要手动改名、迁移或复制 Gateway 文件。
  3. 进入 Capabilities/Settings 时，先按能力与最小权限选择低风险配置，再等待 Hub 显示 Gateway 已就绪。
成功标志：Hub 显示本地 Gateway 可用，或能继续到模型配置界面。首次创建可能较慢；不要重复点击安装或强制关闭窗口。
开机启动边界：XQ 不会自行添加开机启动、计划任务或隐藏服务。若用户在官方 OpenClaw 界面主动开启官方后台组件，那是官方组件行为，不是 XQ 创建的服务。

不要做的事

  • 不要以管理员身份打开终端来“修复” WSL。
  • 不要把完整配置、会话目录或浏览器数据复制给售后。
  • 不要安装第三方插件、Skill、远程 Gateway 或 SSH 隧道来绕过本地设置。
失败时记录 Hub 页面给出的简短提示，转到常见问题或只读诊断。
